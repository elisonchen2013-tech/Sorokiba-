# 🏙️ Sorokiba - Cidade Virtual Online

Sorokiba é um jogo multiplayer em tempo real onde você pode criar contas, trabalhar, ganhar XP e dinheiro, completar missões diárias, participar de eventos e ajudar a cidade a crescer.

## 🚀 Como rodar localmente

### Pré-requisitos
- Node.js 18+ instalado
- npm ou yarn

### Instalação

```bash
# Clonar o repositório
git clone https://github.com/elisonchen2013-tech/Sorokiba-.git
cd Sorokiba-

# Instalar dependências
npm install

# Rodar o servidor
npm start
```

O servidor estará disponível em `http://localhost:3000`

## 🎮 Features

- 👤 **Autenticação**: Criar conta e fazer login
- 💼 **Profissões**: Escolha entre 9 profissões diferentes
- 🎯 **Missões**: Complete missões para ganhar XP e dinheiro
- 🛒 **Loja**: Compre itens para cuidar das suas necessidades
- 🏥 **Hospital**: Recupere sua vida com atendimentos médicos
- 🏦 **Banco**: Gerenzie seu dinheiro
- 👥 **Jogadores**: Veja outros jogadores da comunidade
- 📰 **Notícias**: Leia notícias da cidade (publicadas pelo prefeito)
- 📅 **Eventos**: Participe de eventos
- 📜 **Propostas**: Envie propostas para melhorar a cidade
- 🏛️ **Prefeitura**: Administre a cidade (apenas o prefeito)
- 📊 **Inventário**: Guarde itens comprados
- ⚙️ **Conta**: Veja seu perfil e conquistas

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript Vanilla
- **Backend**: Node.js + Express
- **Banco de Dados**: Em memória (pode ser substituído por MongoDB/PostgreSQL)

1. Faça push do código para o GitHub
2. Conecte seu repositório no Render
3. Defina o comando de início como `npm start`
4. Deploy!
