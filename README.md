# Sorokiba-
🏙️ Sorokiba é uma cidade virtual online onde você e seus amigos podem criar contas, trabalhar, ganhar XP e dinheiro, completar missões diárias, participar de eventos e ajudar a cidade a crescer. Como prefeito, você pode administrar a cidade, controlar impostos, publicar notícias e analisar propostas dos cidadãos.
